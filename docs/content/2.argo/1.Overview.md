# Overview

Argo is a compact carrier board for the Raspberry Pi CM5 and breaks out the following iterfaces:

- PCIe Gen 3 x1 lane
- USB 3.0 (USB-C) and USB-2.0 (only when powered)
- 2x MIPI DPHY (DSI and CSI-2 supported on both)
- 1x Micro HDMI
- I2C, SPI and Fan output
- SD Card Reader (only for CM5 Lite versions)
